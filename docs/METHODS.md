# Workflow methods

1. Read user-supplied polygons and declared CRS; validate nonempty polygon geometry, unique IDs and nonoverlapping interiors. Transform to equal-area EPSG:6933, calculate polygon area, preserve optional AOI and domain identifiers, and record normalized geometry fingerprint. Exact boundary ties are assigned to the first input feature. No convex hull, raster resampling or replacement grid is used.
2. Use configured GEDI V3 collection concept IDs and UTC date bounds. Validate requested beam-relative variables against NASA Harmony capabilities. Add mandatory positioning, identity, land-cover, product-quality and baseline metric fields.
3. Query CMR by domain bounding box and dates, deduplicating product/granule entries in SQLite. Request selected L2 variables through Harmony and selected L4 beam/index ranges through OPeNDAP. Read available source beams from OPeNDAP metadata; missing beam groups are not treated as an error. Clip coordinates to actual polygons before accepting HDF5 subsets.
4. Validate source completeness, shot identifiers, profile dimensions and manifest counts. Index scalar metrics, source/beam/cell references and QC flags while retaining native arrays in HDF5. Record field types, dimensions and attributes. Check assigned geometry and cross-product cell/time/coordinate agreement. Duplicate IDs stop processing for explicit review.
5. Apply the original study's product-specific policy from `src/gedi_aoi/qc_policy.json`: native V3 quality flag equals 1, valid baseline metric, acceptable positioning, defined non-water WorldCover class, urban proportion below 50, valid position/time and sensitivity in (0,1]. L2B positioning derives inclusion from the documented accepted degradation codes because its native include flag is absent. These filters represent the study's analysis choices, not a universal GEDI recommendation.
6. Combine available L4 highest-return orbit outlier flags conservatively: either bad flag excludes the shot; an absent screen remains unknown. Retain otherwise good L2 measurements with unknown orbit screening, and report fully-screened subsets separately. Record sensitivity>=0.95, nighttime and leaf-on variants. Do not impose an extra leaf-on restriction in baseline QC.
7. Write reversible source-linked QC decisions and coverage/date diagnostics. Join usable-shot union across products; preserve per-product flags, provenance and native arrays. Verify each staged and final Parquet value. Native fill values are not silently converted into valid measurements.

The download window is user configured. No other input attributes are copied to shot records. Polygon areas are retained to support later sampling-density calculations; unequal areas require consideration when interpreting counts.

See the NASA guides linked in README for definitions, product limitations, acquisition history and citations. Capability metadata and collection IDs can evolve; this release uses the original project's V3 collections and stops on missing requested paths.
